# RootSpeak landing page — the chosen direction

Mockup **19 «Night sky»**, chosen by the owner on 1 October 2026 among 20 mockups
(same content, twenty visual directions): deep navy, subtle stars, the logo's orbit
as a planetary path and its orange dot as the planet.

- `index.html` — the mockup, a self-contained page without JavaScript (fonts
  embedded and subset to the characters used).
- `preview.png` — the top of the page at 1440 × 900.
- `BRIEF.md` — the content and the rules the mockups followed: only true
  statements, program texts quoted exactly, placeholders where nothing is decided.

Before it becomes the real site: fonts licensed for commercial use (the mockup
uses URW Gothic and other fonts installed locally, for exploring only), prices,
licence terms and download links (now placeholders), the domain.
